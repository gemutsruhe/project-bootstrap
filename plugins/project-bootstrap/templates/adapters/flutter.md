# Flutter adapter

For a new Flutter workspace, use the separately approved `flutter create --no-pub --project-name <project_name> .` command to generate the standard `analysis_options.yaml`, `pubspec.yaml`, Dart entry point, tests, and platform directories. Do not hand-write a reduced Flutter project and do not fetch dependencies without separate command approval.

Create `docs/architecture/interfaces/flutter.md` with mobile platform, permissions, and API contracts.
