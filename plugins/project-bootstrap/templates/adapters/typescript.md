# TypeScript adapter

Generate `tsconfig.json` only after the user chooses Node/runtime and module policy. When Expo is selected, preserve the `tsconfig.json` generated by create-expo-app instead of creating a generic replacement. Document package-manager, Node version, formatting, typecheck, and test commands; do not install packages automatically.

Create the interface record at `docs/architecture/interfaces/typescript.md` with public API contracts and runtime ownership.
